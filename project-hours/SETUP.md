# 工数管理スプレッドシートの作り方

工数管理のスプレッドシートを新しく用意する手順です。
作り方は2通りあります。どちらもブラウザだけでできます（ツールのインストールやリポジトリのチェックアウトは要りません）。

| 方法 | 向いている場合 |
| --- | --- |
| [A. 今のファイルのコピーを作る](#a-今のファイルのコピーを作る) | 新しく使うアカウントから、今の工数管理のファイルを開ける |
| [B. Apps Script エディタに貼り付ける](#b-apps-script-エディタに貼り付ける) | 今のファイルを開けない（GitHub のページを見られれば作れる） |

作り終えたら、どの方法でも [共通の初期設定](#共通の初期設定) に進みます。

---

## A. 今のファイルのコピーを作る

スプレッドシートをコピーすると、紐づいたスクリプト（コードと設定）も一緒にコピーされます。

1. 今の工数管理のスプレッドシートを、新しく使うアカウントに共有します（閲覧者で十分です）。
2. 新しく使うアカウントでそのスプレッドシートを開き、「ファイル」→「コピーを作成」を選びます。
   保存先にそのアカウントのドライブを選び、「共有設定もコピー」はオフにします。
3. コピーしたファイルを開きます。入力済みのシートもコピーされているので、要らないものを消します。
   - 月シート（`2026-10` など）とバックアップのシート：削除します。
   - 案件マスタ：使う案件だけを残します。
   - サマリ：「工数管理」→「サマリを更新」を押すと作り直されます。
4. 1 で付けた共有は外して構いません。

トリガーはコピーされません。[共通の初期設定](#共通の初期設定) の 4 で設定し直してください。

---

## B. Apps Script エディタに貼り付ける

コードは公開リポジトリ https://github.com/c2h1k8/gas-projects にあります。各ファイルを開き、右上の「Raw」を押すと中身だけが表示されるので、それをコピーします。

### 1. スプレッドシートとスクリプトを作る

1. 新しく使うアカウントで、新しいスプレッドシートを作ります（名前は「工数管理」など）。
2. 「拡張機能」→「Apps Script」を開きます。
3. 左のメニューの「プロジェクトの設定」（歯車のアイコン）を開き、次の2つを設定します。
   - 「エディタで "appsscript.json" マニフェスト ファイルを表示する」をオンにする
   - タイムゾーンが「(GMT+09:00) 日本標準時 - 東京」になっているか確認する

### 2. マニフェスト（appsscript.json）を貼る

1. 「エディタ」に戻り、`appsscript.json` を開きます。
2. 中身を全部消して、[project-hours/appsscript.json](appsscript.json) の中身を貼り付けます。
   この中で、タイムゾーンと、報告シートのリンク（スマートチップ）を読むのに使う Sheets API を設定しています。

### 3. コードのファイルを作って貼る

最初からある `コード.gs` は削除します。そのあと、下の表のファイルを**上から順に**作ってください。

- スクリプトは「＋」→「スクリプト」、HTML は「＋」→「HTML」で作ります。
- 名前は拡張子を付けずに入力します（例: `Layout`）。スクリプトには `.gs` が自動で付きます。
- 作ったファイルに、リンク先の中身を全部貼り付けます。

**順番が大事です**。GAS は、エディタに並んでいる順にファイルを読み込みます。`Layout` より後に読み込まれるファイルが、読み込みの時点で `Layout` を使っています。順番が違うと、メニューが出ないなどの不具合になります。順番を間違えたときは、ファイル名の右の「︙」から上下に動かせます。

| 順 | 作るファイル | 種類 | 貼り付ける中身 |
| --- | --- | --- | --- |
| 1 | `DateUtils` | スクリプト | [common/DateUtils.js](../common/DateUtils.js) |
| 2 | `Entrypoints` | スクリプト | [project-hours/Entrypoints.js](Entrypoints.js) |
| 3 | `Layout` | スクリプト | [project-hours/Layout.js](Layout.js) |
| 4 | `MasterSheet` | スクリプト | [project-hours/MasterSheet.js](MasterSheet.js) |
| 5 | `MonthSheet` | スクリプト | [project-hours/MonthSheet.js](MonthSheet.js) |
| 6 | `ReportExporter` | スクリプト | [project-hours/ReportExporter.js](ReportExporter.js) |
| 7 | `SettingsSheet` | スクリプト | [project-hours/SettingsSheet.js](SettingsSheet.js) |
| 8 | `StepActions` | スクリプト | [project-hours/StepActions.js](StepActions.js) |
| 9 | `StepDialog` | スクリプト | [common/StepDialog.js](../common/StepDialog.js) |
| 10 | `Style` | スクリプト | [project-hours/Style.js](Style.js) |
| 11 | `SummarySheet` | スクリプト | [project-hours/SummarySheet.js](SummarySheet.js) |
| 12 | `StepDialogView` | HTML | [common/StepDialogView.html](../common/StepDialogView.html) |

`DateUtils`・`StepDialog`・`StepDialogView` は、ほかのプロジェクトと共有している `common/` フォルダにあります。リポジトリの `project-hours/` フォルダには入っていません。

### 4. 保存する

保存（Ctrl + S）します。エラーが出なければ完了です。

### コードを更新したいとき

変わったファイルの中身を貼り直します。順番は変えずに、中身だけを入れ替えてください。

## 共通の初期設定

1. **メニューを出す**
   スプレッドシートを再読み込みすると、メニューに「工数管理」が出ます。出ないときは、[B の 3](#3-コードのファイルを作って貼る) のファイルの順番を確認してください。
2. **シートを作る**
   「工数管理」→「初期設定（シート作成）」を実行します。
   初回は権限の承認を求められます。スプレッドシート・カレンダー（祝日の判定）・ドライブ（報告ファイル）・Sheets API を使います。
   「このアプリは Google で確認されていません」と出ることがあります。その場合は「詳細」→「（安全でないページ）に移動」で進みます。組織の設定で承認できないときは、管理者に確認してください。
3. **案件と設定を入れる**
   - 案件マスタ：案件コード・案件名・略称を登録し、報告シートに書き込む案件の「報告対象」にチェックを入れます。
   - 設定：入力単位（時間／分）・案件の選び方・入力の刻み・所定労働時間を入れます。報告シートを使う場合は、「報告シートへの反映」の欄（シート名・入力開始行・各列・工数の単位・反映時刻）も入れます。
   - 入力単位・案件の選び方・入力の刻みは、月シートを作るときに決まります。すでにある当月シートに反映したいときは、「当月シートを作り直す」を実行してください。
4. **トリガーを設定する**
   「工数管理」→「トリガーを設定」を実行します。次の3つが設定されます。
   - 毎月1日0時台に、当月シートを作る
   - 毎日、設定シートの反映時刻に、報告シートへ書き込む
   - 案件マスタを編集したら、サマリを更新する
   設定シートの反映時刻を変えたときは、もう一度「トリガーを設定」を実行します。
5. **報告ファイルを貼る（使う場合）**
   サマリの「報告シート」列に、月ごとの報告ファイルのリンクを貼ります（URL・リンク・スマートチップのどれでも可）。
   「表示中の月を報告シートへ反映」で試してから、毎晩の自動反映に任せます。最初は、お客様のファイルのコピーで試すことをおすすめします。

## 確認しておくこと

- スプレッドシート自体のタイムゾーン（「ファイル」→「設定」）も日本になっているか確認します。今日の行の色付けや見込みの計算は、シートの `TODAY()` で判定します。
- 報告ファイルは、月ごとに別のファイルにします。同じファイルを2つの月に貼ると、お互いの内容を上書きしてしまいます。
