# リッチメニュー画像の実測値

`build-richmenu-images.py` が使っている寸法・配色の根拠。初代の画像（手作業で作成）から
ピクセルを実測して求めたもの。作り直しの際に見た目がずれないよう記録しておく。

## キャンバス

| 項目 | 値 |
| --- | --- |
| サイズ | 1200 × 810 |
| 背景色 | `#F5F7FA` |
| タブ帯 | 高さ 132px / `#ECF2FC` |
| 選択中タブ | `#4A86E8` / 幅 364px / 角丸 26px |
| ボタン領域 | 3列 × 2行、1マス 400 × 339 |

## カード

| 項目 | 値 |
| --- | --- |
| 余白 | マスの全周 24px（カード実寸 352 × 291） |
| 角丸 | 31px |
| 上端からアイコンまで | 37px |
| タイトル | 41px / `#2D3442` / weight 600 |
| 説明 | 23px / `#9298A4` |
| アイコン下〜タイトル | 49px |
| タイトル〜説明 | 12px |

グリフの占める位置はマス基準で、タイトルが y=238〜273、説明が y=290〜309。

## アイコン

| 項目 | 値 |
| --- | --- |
| サイズ | 126 × 126 |
| 角丸 | 44px（辺長の約35%。かなり丸い） |
| グリフ | 64px・白 |
| グラデーション | **垂直**（180deg）。斜めではない |
| 影 | 下端色を落とした色付きグロー。`0 11px 20px -3px <下端色>80` |

グラデーションは上端・下端から8px内側で採色した値。

| 配色 | 上 | 下 |
| --- | --- | --- |
| green | `#6BC894` | `#32B36B` |
| orange | `#F9C07E` | `#F8A84C` |
| teal | `#66CBC7` | `#2AB7B1` |
| blue | `#7FA9EE` | `#4E88E8` |
| red | `#F297A2` | `#EE6F7E` |
| purple | `#9797E7` | `#6F6FDE` |
| gray | `#B3B7BF` | `#9AA0AB` |

## 注意

- 画像を差し替えたら Drive 上のファイル（`line-attendance-richmenu-{a,b,c}.png`）も
  置き換えたうえで `SetupRichMenu` を実行すること。ファイル名で検索している。
- 枠の増減は `RichMenuSetup.js` の `areas` と本スクリプトの `PAGES` の両方を直す。
